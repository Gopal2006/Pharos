# Roadmap

## Phase 1 — Foundation
- Establish application, development scripts, tests, and CI.
- Finalize requirements and technical decisions.
- Maintain product, architecture, and security documentation.

## Phase 2 — GitHub integration (implemented in v0.2)
- Validate public repository URLs.
- Implement typed API client and error handling.
- Fetch metadata, README, and repository trees.
- Handle rate limits and transient failures.

## Phase 3 — Deterministic analysis (initial support implemented in v0.2)
- Implement supported manifest parsers.
- Extract setup commands and scripts.
- Add source-linked findings and contribution instructions.

## Phase 4 — Interface (repository analysis implemented in v0.2)
- Build landing page and repository dashboard.
- Expand navigation and analysis coverage.

## Phase 5 — Release
- Complete automated tests and security review.
- Deploy to Vercel.
- Publish documentation, screenshots, and release notes.

## Phase 6 — Post-MVP
- Saved repositories and notes.
- More analyzers and contribution insights.
- Optional AI explanations.
- Additional caching or server-side functionality where justified.
