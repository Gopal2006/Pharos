# Contributing

Thanks for your interest in Pharos.

## Development setup

Requirements: Node.js 20.19+ or 22.12+, and npm.

```bash
npm install
npm run dev
```

## Before submitting changes

```bash
npm run lint
npm run typecheck
npm run test
npm run build
```

## Contribution guidelines

- Keep changes focused and explain the problem they solve.
- Add or update tests for behavior changes.
- Keep repository analysis evidence-backed and deterministic.
- Do not commit secrets, tokens, or personal credentials.
- Update documentation when behavior or setup instructions change.

## Pull requests

Describe the problem, summarize the implementation, list the tests performed, and include screenshots for meaningful UI changes.
